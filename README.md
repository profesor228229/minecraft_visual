# Nebula Visuals — визуальный клиент для Minecraft 1.16.5 (Fabric)

Чисто визуальный клиент: без читов, только красота, плавность и удобство.
Все анимации не зависят от FPS (экспоненциальное сглаживание + easing-кривые).

## Установка
1. Fabric Loader для **1.16.5** + **Fabric API** (`0.42.0+1.16`).
2. Собрать: `gradle build` (или открыть проект в IntelliJ IDEA → Gradle → `build`).
   > В репозитории нет `gradle-wrapper.jar`. Один раз выполните `gradle wrapper --gradle-version 8.7`, после этого работает `./gradlew build`.
   > Для сборки нужен JDK 17+ (итоговый мод нацелен на Java 8 и запускается на Java 8/11/16/17).
3. Положить `build/libs/nebula-visuals-1.0.0.jar` в `.minecraft/mods`.

## ClickGUI — **Правый Shift**
- Открывается и закрывается с анимацией масштаба (easeOutBack), фон затемняется и размывается (опционально).
- **ЛКМ** по модулю — включить/выключить, **ПКМ** — раскрыть настройки (плавно), **СКМ** — назначить бинд.
- **ЛКМ по заголовку** — перетащить панель, **ПКМ по заголовку** — свернуть панель.
- Колесо мыши — прокрутка панели (с плавным скроллом, скроллбаром и затуханием по краям).
- **Просто начните печатать** — появится поиск по модулям. `Esc` очищает поиск, `Ctrl+Backspace` удаляет всё.
- При наведении на модуль показывается его описание.
- **HUD-редактор встроен**: пока GUI открыт, любой HUD-элемент можно перетащить мышью (есть направляющая по центру экрана).
- Настройки: переключатели, слайдеры, режимы (ЛКМ вперёд / ПКМ назад), HSB-палитра цветов, бинды (`Esc`/`Del` — сбросить бинд).
- Позиции панелей, HUD, настройки и бинды сохраняются в `config/nebula/config.json`.

## Модули
| Категория | Модуль | Описание |
|---|---|---|
| HUD | Watermark | Логотип, FPS, пинг, время; ширина меняется плавно |
| HUD | ArrayList | Анимированный список модулей (выезд, сортировка, градиент, свечение); автоматически выравнивается по правому/левому краю |
| HUD | TargetHud | Голова цели (краснеет и сжимается при ударе), плавная полоска HP с «отложенным» уроном, частицы, Winning/Losing |
| HUD | Keystrokes | WASD / ЛКМ / ПКМ / пробел с анимацией нажатия |
| HUD | Potions | Эффекты зелий (мигают перед концом), можно скрыть ванильные |
| HUD | Info | Координаты, координаты в Незере, скорость (b/s), направление |
| Render | Crosshair | Cross / Circle / Dot, динамический разброс, индикатор кулдауна атаки |
| Render | BlockOverlay | Выделение блока, которое плавно «переезжает» между блоками |
| Render | HitParticles | Светящиеся частицы при ударе (Orbs / Sparks / Stars) с физикой и отскоками от блоков |
| Render | JumpCircles | Расходящиеся градиентные кольца при прыжке |
| Render | ChinaHat | Градиентная шляпа-конус (себе и/или другим) |
| Render | TargetEsp | Circle / Souls / Box вокруг цели, краснеет при ударе |
| Render | Trails | Плавный шлейф за игроком |
| Render | NoRender | Убрать тряску камеры, огонь, погоду, виньетку, боссбар |
| World | Fullbright | Плавное включение/выключение яркости |
| World | TimeChanger | Время суток на клиенте, плавный переход или цикл |
| World | Fireflies | Светлячки вокруг игрока |
| Player | ViewModel | Позиция / масштаб / поворот рук |
| Player | SlowSwing | Скорость анимации взмаха рукой |
| Player | Zoom | Зажмите **C** — плавный зум, колесо регулирует кратность |
| Client | ClickGui | Тема: два акцентных цвета, радуга, скорость волны, блюр, масштаб GUI |
| Client | Notifications | Всплывающие уведомления с прогресс-баром |

Все цвета во всех модулях берутся из темы (`ClickGui → Accent / Accent 2 / Rainbow`).

## Структура
```
dev.nebula
├── Nebula.java            точка входа, события
├── config/                сохранение JSON
├── gui/                   ClickGUI: экран, панели, кнопки, компоненты настроек
├── mixin/                 хуки в рендер/ввод
├── module/                модули по категориям
├── setting/               типы настроек
└── util/                  анимации, easing, 2D/3D-рендер, цвета, тема
```
